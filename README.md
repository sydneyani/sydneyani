## What I work on

**Snowflake BI and data warehousing.** Daily warehouse development, including Snowflake’s built-in AI for data validation, and support for consolidating ERP data into OneBI.

**Data validation.** A Python Flask application with Snowflake SSO and the Snowflake API for ETL readiness checks, delta-variance analysis, and cross-column comparisons. LLM-assisted workflows flag schema mismatches and variance spikes across multiple ERP systems.

**Applied AI on the team.** AI enablement lead for the group, including training sessions, and AI automation in GitHub Actions workflows.

**Software and analytics engineering.** Applications in C# and Flutter, REST API automation, and Python/SQL analytics. Machine learning pipelines with pandas, NumPy, scikit-learn, and XGBoost for forecasting and classification, on Azure, with occasional Databricks use.
